OPEN AGENTIC STACK

Estándares & Conceptos Agentic

La nueva generación de sistemas autónomos se construye sobre protocolos abiertos, gateways de conectividad segura, aislamiento con MicroVMs y gobernanza verificable.

Protocol · 01 aaif.io

Model Context Protocol (MCP) ↗

Model Context Protocol (MCP) is a protocol for seamless integration between LLM applications and external data sources.

Protocolo abierto que estandariza cómo las aplicaciones con LLMs descubren y se conectan de forma fluida con herramientas y fuentes de datos externas.

Spec · 02 aaif.io

AGENTS.md ↗

AGENTS.md is a simple, open format for guiding coding agents.

Formato abierto y declarativo dentro del repositorio para guiar a los agentes de programación sobre arquitectura, convenciones y flujos de validación.

Interop · 03 aaif.io

Agent2Agent (A2A) ↗

Agent2Agent (A2A) is an open protocol that enables AI agents to communicate, collaborate, and securely exchange information and tasks across different platforms and frameworks.

Interoperabilidad abierta para que agentes construidos en distintos frameworks colaboren, deleguen tareas e intercambien contexto de manera segura.

Connectivity · 04 aaif.io

agentgateway ↗

agentgateway enables secure, scalable connections between AI agents, models, tools, and APIs across ecosystems.

Plano de conectividad seguro y escalable entre agentes de IA, modelos, herramientas y APIs empresariales a través de múltiples ecosistemas.

Envoy Gateway · 05 aaif.io

Agent Router ↗

Agent Router is an open source AI gateway built on Envoy that connects applications to models and MCP tools while platform teams manage access, routing, and usage.

AI gateway open source sobre Envoy que conecta aplicaciones con modelos y herramientas MCP mientras los equipos de plataforma gestionan acceso, ruteo y consumo.

Runtime · 06 docker.com

Docker Sandboxes · MicroVM Isolation ↗

MicroVM isolation for every agent session, local or cloud. Network and filesystem locked down at the runtime.

Aislamiento dedicado con MicroVMs por cada sesión de agente, local o en la nube, con red y sistema de archivos restringidos directamente desde el runtime.

Governance · 07 Autonomy & Safety

AI Governance: Unlock Agent Autonomy, Safely

Desbloquear la autonomía de los agentes en producción requiere gobernanza desde la arquitectura: políticas de mínimo privilegio, identidad verificable por agente, auditoría sobre llamadas MCP/A2A y ejecución confinada en MicroVMs.
